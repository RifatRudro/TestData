# Bundled resource files

* `newly_discovered_duplicates.csv`, `near_duplicates_different_times.csv`, `dermamnist_e_labels.csv` -
  from https://github.com/kakumarabhishek/Corrected-Skin-Image-Datasets (Abhishek, Jain & Hamarneh,
  "Investigating the Quality of DermaMNIST and Fitzpatrick17k Dermatological Image Datasets",
  Scientific Data, 2025). `dermamnist_e_labels.csv` holds the official ISIC 2018 Task 3 train/val/test
  labels (test without ISIC_0035068). Cite that paper and the ISIC 2018 / HAM10000 papers when used.
* `literature.csv` - numbers from the user's literature table (abstract-level; verify before citing)
  plus PLCRD (arXiv 2607.18773) and the ISIC 2018 Task 3 winner (88.5% balanced accuracy).
